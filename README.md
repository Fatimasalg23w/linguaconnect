# LinguaConnectAcademy - React + Vite

## Instalación

```bash
npm install
```

## Desarrollo

```bash
npm run dev
```

## Build para producción

```bash
npm run build
```

## Importante

- Coloca tu logo como `public/logo.png` para que se muestre correctamente
- Los videos se cargan desde Pexels directamente
- Todos los videos tienen autoplay, muted y loop activados

## Características

- ✅ Colores pastel (morado, cyan, mint)
- ✅ Video en hero section (lado izquierdo y derecho, debajo de la tarjeta)
- ✅ Video en sección de descuentos universitarios (estudiantes trabajando)
- ✅ Video en sección de voluntariado (experiencia real)
- ✅ Footer en lila claro
- ✅ Diseño responsivo
- ✅ Estilo Odoo moderno
